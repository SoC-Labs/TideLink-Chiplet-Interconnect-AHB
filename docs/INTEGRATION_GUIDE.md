# Integration Guide — Consuming the `tidelink` Subsystem

How to wire the TideLink chiplet-interconnect subsystem (`tidelink_top`) into a
host SoC, fetch and build its dependencies, build it for FPGA or ASIC, and bring
it up from cold POR to verified link traffic.

This guide does **not** repeat the register-bit or protocol detail — for those
see [REGISTER_MAP.md](REGISTER_MAP.md) (every APB/SWI register), [IMPLEMENTATION.md](IMPLEMENTATION.md)
(FSM / protocol / CDC), and [ARCHITECTURE.md](ARCHITECTURE.md) (component & port
breakdown). The authoritative spec is [TIDELINK_SPECIFICATION.md](TIDELINK_SPECIFICATION.md).

**Audience:** SoC integrators instantiating `tidelink_top` in a host bus matrix,
and bench/ASIC engineers bringing the result up.

### 1.2 Environment setup

Always source `set_env.sh` before any tool invocation:

```bash
source set_env.sh
```

It exports `TIDELINK_HOME`, `CMSDK_DIR`, `CMSDK_FPGA_SRAM_V`, `XHB500_IP_DIR`,
and `XHB500_GEN_DIR`, and — on first run — generates the two XHB500 bridges
(`xhb_chiplet_slv`, `xhb_chiplet_mst`) into `deps/xhb500/generated/` from the
configs in `deps/xhb500/configs/`. Subsequent runs skip generation if the output
exists.

Vendor-IP env vars point at the shared lab IP library
(`${ARM_IP_LIBRARY_PATH}/...`) and are overridable — never edit files under those
trees. `cmsdk_fpga_sram.v` is missing from some BP210 installs; `set_env.sh`
falls back to a standalone path (see
[archive/DEPENDENCIES.md](archive/DEPENDENCIES.md)).

### 1.3 Submodules

```bash
git submodule update --init --recursive
```

| Submodule | Provides |
|---|---|
| `deps/axi-chiplet-controller` | Wlink (LL+TL+CRC/ECC+GPIO PHY), `axi_chiplet_controller.sv` (APB regs, autoneg FSM, I²C, IDELAYE2/BUFG wrappers), I²C cores, XHB500 generator output |
| `deps/xhb500` | XHB500 AHB↔AXI bridge generator output (also (re)generated by `set_env.sh`) |
| `deps/tidelink-gpio-phy` | GPIO-PHY training/match rewrite: spec, pattern-search tooling, and the new lane-checker / calibrator-scoring RTL |

The `axi-chiplet-controller` `.gitmodules` tracks `main`; the recorded parent SHA
resolves regardless of branch. Wlink-generated files carry hand-applied TideLink
patches — re-apply them on any Chisel regen (see
[archive/DEPENDENCIES.md](archive/DEPENDENCIES.md) §"Updating Dependencies").

## 3. Flists — picking a build target

Flists live in `flist/` and reference RTL via `${TIDELINK_HOME}`/`${CMSDK_DIR}`,
so `set_env.sh` must be sourced first. The top-level ones:

| Flist | Use |
|---|---|
| `tidelink_fpga.flist` | FPGA `tidelink_top`: BRAM-inferred SRAM (`cmsdk_fpga_sram`), pre-generated Wlink, ASIC-only cells stripped |
| `tidelink_asic.flist` | ASIC `tidelink_top`: TSMC65 `rf_16k` SRAM macro, stdcell/DFT collateral |
| `tidelink_generic.flist` | Behavioural SRAM model — sim / lint only |
| `tidelink_top.flist` | `tidelink_top` integration (sim) |
| `tidelink_top_full_asic.flist` | Full-chiplet ASIC partition (`make fc ASIC_MODULE=tidelink_top_full`) |

Module/feature flists (`tidelink_fifo.flist`, `tidelink_apb_regs.flist`,
`tidelink_returner.flist`, `tidelink_idelay_rx.flist`, `tidelink_rxclk_buf.flist`,
`tidelink_lane_checker.flist`, etc.) drive their own unit-sim/lint targets.

**Pick by target:** FPGA build → `tidelink_fpga.flist`; ASIC synth →
`tidelink_asic.flist` / `tidelink_top_full_asic.flist`; everything else is a
unit-level filelist. Apply RTL additions to **both** the FPGA and ASIC flists to
avoid the split-brain noted in [archive/DEPENDENCIES.md](archive/DEPENDENCIES.md).

## 4. Wiring into a host SoC

`tidelink_top` is a drop-in chiplet subsystem (the reference target replaces
`nanosoc_ss_chiplet_mng` in nanosoc-chiplet-tech). It exposes four AHB ports, an
APB config port, and an AXI-Stream extension port.

### 4.1 The four AHB ports

| Port | Direction | Function | Bring-up note |
|---|---|---|---|
| `ahb_sub_*` | subordinate | Transparent bridge to peer via XHB500→AXI→Wlink; address-translated | Safe with link down (HREADY returned locally) |
| `ahb_tx_*` | subordinate | Direct TX aperture into the local FC node (no translation) | **WEDGE HAZARD** — a write with link down hangs the bus; gate behind a verified-link check |
| `ahb_fifo_*` | subordinate | Local RX FIFO read window (drain received packets) | Safe |
| `ahb_mng_*` | manager | Incoming credit-return / doorbell / FC writes from the peer, routed through XHB500 | Safe |

Connect `ahb_sub_*`, `ahb_tx_*`, `ahb_fifo_*` as subordinates on the host bus
matrix and `ahb_mng_*` as a manager. The APB config port carries Region 0–8
registers (Wlink @ base+`0x30000`, TideLink @ base+`0x32000` in the reference
map; see [REGISTER_MAP.md](REGISTER_MAP.md) and
[reference_tidelink_address_map] in memory — peer aperture `0x40000000`, local RX
FIFO `0x44010000`). PTP has its own AHB slave (`tidelink_ptp`) and the external
PHC IP its own APB port.

### 4.2 AXI-Stream extension (TideChart) + sideband

`tc_axis_tx_*` / `tc_axis_rx_*` forward PKT_EXT (FC `pkt_type=2'b10`) to/from an
external TideChart controller; `tl_local_link_state_o[4:0]` is a quantised
congestion sideband. Tie off if unused.

### 4.3 Parameters & wrapper selection

`tidelink_top` parameters (declared at `src/rtl/tidelink_top.sv:38–108`):

| Parameter | Default | Meaning |
|---|---|---|
| `SYS_ADDR_W` / `SYS_DATA_W` | 32 / 32 | Bus geometry |
| `RAM_ADDR_W` / `RAM_DATA_W` | 14 / 32 | FIFO SRAM (16 KB default) |
| `APB_ADDR_W` | 12 | APB register address width |
| `FC_DATA_W` | 48 | FC-node data width |
| `NUM_PHY_LANES` | 8 | GPIO PHY lanes |
| `TIDELINK_PAIR_BASE` | 0 | Peer APB base (also runtime via `PAIR_BASE_ADDR`) |
| `USE_IDELAY` / `USE_CLKBUF` / `USE_T3A` | `1'b0` | **FPGA-only RX paths** — default 0 (ASIC); FPGA wrapper overrides to 1 via `component.xml` |
| `NEGO_CFG_RESET` | `7'h61` | Autoneg reset (`nego_en\|force_lock\|mask_hs_auto_en`) |

The calibrator inside `tidelink_top` runs with `AUTOCAL_ENABLE(1'b1)`
(`tidelink_top.sv:1845`) — the old AUTOCAL=0 workaround is reverted.

**Wrapper selection is by flist + parameter, not by separate top files:**
- **ASIC:** instantiate `tidelink_top` with `USE_*` at their `1'b0` defaults and
  build with `tidelink_asic.flist`. The per-lane delay-cell macro is the ASIC
  analogue of IDELAYE2.
- **FPGA:** the packaged IP wrapper drives `USE_IDELAY=1`, `USE_CLKBUF=1`,
  `USE_T3A=1` (per-bank `IDELAYCTRL` caveats apply — some FPGA targets bypass
  IDELAY). Build with `tidelink_fpga.flist`. **Do not delete the `USE_*` paths**
  — they are FPGA-essential.

## 5. FPGA build + deploy flow

### 5.1 Build

```bash
source set_env.sh

# Single-board (fastest)
make -C fpga build_design TARGET=pynq-z2-single

# HW-validated pair (recommended for sign-off) — two targets in parallel
bash fpga/scripts/build_farm.sh \
    pynq-z2-pair-all@local \
    pynq-z2-pair-flip-all@srv04936
```

`TARGET` selects the board config from `fpga/targets/` (valid values are
enforced in `fpga/Makefile`: `pynq-z2-single`, `pynq-z2-pair[-flip][-slow|-ila|-all]`,
`pynq-z2-pair-mmcmbypass-*`, `pynq-z2-loopback[-ext]`, `mps3`). Concurrent farm
targets `make -C fpga build_pair_farmed` / `build_pair_concurrent` exist for
cross-host parallel pair builds. Each Vivado run is ~40–60 min; bitstreams land
in `imp/fpga/output/<TARGET>/tidelink.bit`.

**Gate before deploy** (per the validation runbook): sim must be green first —
`make lint`, `make sim-regression` (paired `tidelink_top_pair` cocotb),
`tidelink-gpio-phy` unit tests, and the integrated paired-die env. Then Vivado
reports must show timing met (WNS ≥ 0) and no critical warnings on the new
checker/calibrator instances. Sim-gate before every HW deploy is project policy.

### 5.2 Stage + deploy on bridge1 (PYNQ-Z2 pair)

```bash
# 1. .bit -> .bin + provenance manifest (UNVERIFIED deploys hard-abort)
python3 fpga/scripts/bit2bin.py imp/fpga/output/pynq-z2-pair-all/tidelink.bit ~/td_milestone_stage/tidelink.bin
bash pynq_host/scripts/make_bitstream_manifest.sh ~/td_milestone_stage/tidelink.bin \
    --commit "$(git rev-parse HEAD)" --target pynq-z2-pair --lock-min 14
# (repeat for the -flip image)

# 2. Lease — MUST be GRANTED, not queued
ssh mapstone-dev "/opt/fpgahub/bin/fpgahub pair lease acquire bridge1 --user \$(whoami) --ttl 5400"
ssh mapstone-dev "/opt/fpgahub/bin/fpgahub pair lease show bridge1"   # verify "granted to <you>"

# 3. Stage .bin/.hwh + *.manifest.json to mapstone-dev:/tmp/tidelink_deploy/, then converge
ssh mapstone-dev "cd ~/SoCLabs/tidelink && bash pynq_host/scripts/bringup_pair_converge.sh STABLE=3 MAX_RETRIES=15"
```

Acceptance: `RESULT: CONVERGED — full 16/16 bidirectional link`. Full phased
checklist (lease → deploy → APB readback → functional bring-up → ILA → PHC soak →
tear-down, with abort matrix) is in
[archive/HW_VALIDATION_RUNBOOK_GPIO_PHY_INTEG.md](archive/HW_VALIDATION_RUNBOOK_GPIO_PHY_INTEG.md).

Bring-up pitfalls (lease-granted, AHB_TX wedge hazard, manifest provenance,
WavD2DGpioRx count-phase lottery) are documented in
[archive/TIDELINK_BRINGUP_USER_GUIDE.md](archive/TIDELINK_BRINGUP_USER_GUIDE.md) §5.

## 6. ASIC flow pointer

The ASIC PnR / GDSII flow is exposed at the repo root via `flows/makefile.asic`:

```bash
make fc        # Fusion Compiler synth
make gdsii     # GDSII
make fc_lec / fc_etm / fc_all / asic_stage / asic_clean
# Override the partition: make fc ASIC_MODULE=<name>   (default tidelink_top_full)
```

Build from `tidelink_asic.flist` (or `tidelink_top_full_asic.flist`). Sign-off
gates: STA at all PVT corners with source-sync arcs analysed
([ASIC_TIMING_CONSTRAINTS.md](ASIC_TIMING_CONSTRAINTS.md)), SpyGlass CDC
(`make -C cdc cdc`, see [CDC_AUDIT_REPORT.md](CDC_AUDIT_REPORT.md)), and per-lane
skew determinism ([DETERMINISM_VALIDATION.md](DETERMINISM_VALIDATION.md)). The
ASIC target runs the GPIO pad clock at ~100 MHz (UI = 10 ns; calibrator phase
step ≈ 0.625 ns) vs 25 MHz on FPGA.

## 7. APB bring-up sequence (summary)

Identical RTL behaviour on FPGA and ASIC; full register detail in
[REGISTER_MAP.md](REGISTER_MAP.md), FSM detail in [IMPLEMENTATION.md](IMPLEMENTATION.md).
Addresses below use the reference map (Wlink `0x44030000`, TideLink `0x44032000`).

1. **Role.** Write `ROLE_CFG @ 0x44032084` bit[1]=1 to latch `role_locked`
   (strap/OTP/I²C-autoneg select the role bit; natural autoneg never converges
   without this). Set `PAIR_BASE_ADDR @ 0x44032000` to the peer's APB base.
2. **Calibrate.** Wlink POR deasserts; the calibrator sweeps slip×phase per lane.
   Poll `SWI_LANE_STATUS @ 0x44032108` for `lane_locked[7:0]=0xff`,
   `lane_fault[15:8]=0x00`, `cal_done[16]=1` on both sides. Recal pulse if needed
   (`SWI_TRAINING_MODE` slot0 `0x3 → 0x1`).
3. **Drop training → bootstrap data mode (load-bearing).** Write
   `SWI_TRAINING_MODE @ 0x44032100 = 0`, then cycle `WL_EnableReset @ 0x44030208`:
   `0x00027f08 → 0x00027f00 → 0x00027f07` (≥5 ms / ≥5 µs between writes) on both
   sides. Skipping this leaves the link in training and no credit packet drains.
4. **Verify credit handshake.** `SWI_LANE_STATUS` bit[23] `cr_pkt_seen_rx = 1`
   both sides; `PAIR_CREDIT_COUNTER @ 0x44032028` non-zero both sides.
5. **Application traffic.** AHB_SUB peer write (safe), doorbell
   (`DOORBELL @ 0x44032014` → peer `DOORBELL_RESPONSE_ACC @ 0x44032024`), PHC sync.
   Never poke `ahb_tx_*` (`0x4400_0000`) until the link is verified up.

On the FPGA pair, `bringup_pair_converge.sh` automates steps 1–2;
`sw_coord_autocal_region8.sh` adds step 3. The verification register table and
troubleshooting decision tree are in
[archive/TIDELINK_BRINGUP_USER_GUIDE.md](archive/TIDELINK_BRINGUP_USER_GUIDE.md)
§4 and §6.
