# tidelink_fpga.flist — Notes

## FPGA SRAM choice
`src/rtl/fifo/fpga/tidelink_sram.sv` wraps `cmsdk_fpga_sram` (Arm CMSDK BRAM model).
Port signature is identical to the ASIC rf_16k wrapper — only the internal
implementation changes. Vivado infers block RAM from `cmsdk_fpga_sram`'s
synchronous read/write structure. No additional wrapper was needed.

## Wlink Verilog generation
Pre-generated Verilog is committed at `deps/axi-chiplet-controller/logical/wlink/`
(configuration: `wav.wlink.Wlink8LaneAXI32bitConfig`).

To regenerate (requires Java 8+, sbt):
```
make -C deps/axi-chiplet-controller wlink \
     CONFIG=wav.wlink.Wlink8LaneAXI32bitConfig \
     OUTPUTDIR=$(pwd)/deps/axi-chiplet-controller/logical/wlink
```
sbt is available at `/usr/bin/sbt` on this build host.

## ASIC-only cells stripped vs tidelink_top_full_asic.flist
- `src/rtl/fifo/asic/tidelink_sram.sv` (rf_16k macro, TSMC 65nm) — replaced by fpga variant
- `tidelink_netlist.flist` entries (`tidelink.mapped.v`, stdcell lib `.v`, rf_16k.v) — excluded
- No DFT/scan collateral present in RTL source; none added here

## Known tie-offs / stubs
- PUF SRAM: no separate macro — the TideChart PUF entropy path reads out of
  the shared FIFO SRAM (tidelink_sram inside tidelink_fifo_mem). No tie-off needed.
- `WavClockGate` / `WavClockInv` / `WavClockMux`: Chisel-generated clock helpers
  included as-is; Vivado will map them to BUFGMUX/LUT primitives. If clock gating
  causes timing issues, replace with Vivado clock-gating primitives in the IP wrapper.

## Environment prerequisites
Source `set_env.sh` before invoking Vivado or iverilog:
```
source set_env.sh   # sets TIDELINK_HOME, CMSDK_DIR, XHB500_GEN_DIR
```
XHB500 bridges are auto-generated by `set_env.sh` if not already present (requires
Arm XHB-500 IP at `$XHB500_IP_DIR`).
