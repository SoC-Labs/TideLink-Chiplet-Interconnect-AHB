# farm_gate.sh — sv_anti_pattern_lint accepted-baseline ratchet
# ==============================================================
# Each non-comment line is a KNOWN, accepted first-party sv_anti_pattern_lint
# finding. The gate fails on findings NOT listed here (i.e. a NEW latch /
# incomplete-case regression), so it is green today yet still catches new
# anti-patterns.
#
# Format: "<relpath-from-TIDELINK_HOME>: <CODE> [key=<discriminator>]"
#         — CONTENT-KEYED. No line number. See fpga/farm_gate.sh `extract_keys`.
# To retire a baseline entry, fix the RTL and delete the line.
#
# ── WHY THERE IS NO LINE NUMBER ANY MORE (2026-08-24) ────────────────────────
# This file previously keyed on "<path>:<line>: <CODE>". That was a POSITION
# key, and the header used to carry a drift ledger reading
#
#     941 -> 985 -> 1021 -> 1089 -> 1102
#
# for ONE unchanged always_comb — the axi_chiplet_controller.sv APB read mux —
# plus 382/383 -> 541/542 -> 584/585 -> 600/601 for the autoneg case. At HEAD the
# mux had drifted again, to 1166, a sixth shift with no edit to the block. Five
# of this file's six commits are that churn; their own subjects say so
# ("pure line-drift", "line-number refresh", "re-ratchet ... for ... line shift").
#
# THE COST WAS NOT THE CHURN. Every drift turned the gate RED with the message
# "NEW finding(s)", and the trained response is to paste current lint output over
# this file. That accepts, unread, anything genuinely new that arrived in the same
# window — while this file's own "independently read-verified" claim goes on
# asserting that somebody looked. One farm build (BUILD_REGISTRY.yaml
# BLD-2026-07-28-z2-trainfb) was launched on a tree dirtied by an uncaptured
# baseline refresh, which is that failure mode leaving a mark.
#
# A stale entry was also a permanent free pass: `gone` keys are reported with
# `say`, never `fail`, so ":1102" stayed a pre-waived slot for whatever might
# later land on line 1102.
#
# Keys are now emitted by the linter (`[key=...]`) and are position-independent.
# They are also STRICTLY MORE SELECTIVE than the old key: COMB_NO_DEFAULT stamps
# every unguarded signal in a block with the same always_comb header line, so a
# second latched signal inside an already-baselined block used to be a
# byte-identical key and passed SILENTLY — the exact class this gate exists to
# catch. It now has its own key. Where a key legitimately repeats (the two `di`
# iterators below) the ratchet counts occurrences, so a third one still fails.
#
# ── THE ACCEPTED FINDINGS, each read-verified as a FALSE POSITIVE of the
#    lint's top-of-block-default heuristic — no synthesizable latch is inferred:
#
#   * axi_chiplet_controller.sv `ctrl_reg_rdata` — APB read mux. `unique case
#     (ctrl_reg_addr[4:3])` enumerates all four 2-bit arms AND carries an
#     explicit `default: ctrl_reg_rdata = 32'b0;`. Every path assigns; flagged
#     only for lacking a pre-case default.
#   * tidelink_autoneg.sv `selected_priority` / case `(nego_pri_sel)` — the case
#     is fully enumerated (2-bit nego_pri_sel, all 4 arms 2'd0..2'd3 assigned) so
#     no real latch is inferred; the lint wants a defensive `default:` for
#     tool-version safety.
#   * tidelink_lane_deskew_v2.sv `ci` / `di` (x3) — the flagged name in each case
#     is an `integer` FOR-LOOP ITERATOR (`for (ci|di = 0; ...)`), unconditionally
#     reset to 0 on every always_comb entry, so it can never latch. Each block
#     opens with explicit top-of-block defaults for its REAL outputs
#     (ep_changed, ep_max_d/ep_min_d/ep_seen_active, max_dist/min_dist/
#     sr_seen_active) and writes the full per-lane array every iteration.
#     NO inferred latch. TWO of the three are keyed `di` and are listed twice
#     below ON PURPOSE — that is the occurrence count, not a duplicate.
#
# These are pre-existing / verified-benign debt, tracked here so the gate
# ratchets forward.
src/rtl/local_overrides/axi_chiplet_controller.sv: COMB_NO_DEFAULT [key=ctrl_reg_rdata]
src/rtl/local_overrides/tidelink_autoneg.sv: CASE_NO_DEFAULT [key=(nego_pri_sel)]
src/rtl/local_overrides/tidelink_autoneg.sv: COMB_NO_DEFAULT [key=selected_priority]
src/rtl/local_overrides/tidelink_lane_deskew_v2.sv: COMB_NO_DEFAULT [key=ci]
src/rtl/local_overrides/tidelink_lane_deskew_v2.sv: COMB_NO_DEFAULT [key=di]
src/rtl/local_overrides/tidelink_lane_deskew_v2.sv: COMB_NO_DEFAULT [key=di]
