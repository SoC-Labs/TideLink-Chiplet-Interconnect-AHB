About this tool / how to read the heatmap

What this tool is for

The TideLink GPIO PHY has 8 lanes per direction; each lane has a 4-bit swi_phase_offset that selects which cycle of the 16-cycle deserialiser word writes each bit position. The correct phase per lane depends on physical channel skew, which is heterogeneous across lanes and changes per deploy (count-skew lottery). This tool sweeps the global swi_phase_offset from 0..15 and renders per-lane lock state, exposing the per-lane eye margin and revealing whether the calibrator picked good per-lane phases. Despite the historical "live-eye" name, this is not a conventional time-domain eye diagram — it is a per-lane phase-vs-lock heatmap.

What each control does

  • Stage dir — where the bitstream files (tidelink.bin, tidelink-flip.bin) live on mapstone-dev. Default /tmp/tidelink_deploy.
  • Master IP / Slave IP — SSH endpoints for the two paired boards (typically 192.168.4.101 and 192.168.6.101).
  • Board — fpgahub board name for the lease and bitstream loading (e.g. pynq_z2_02 or pynq_z2_03).
  • Use currently deployed (checkbox) — assume the bitstream is already loaded; skip the JTAG/USB-IP load step. Use when you have manually deployed and want to sweep without re-flashing.
  • Skip converge (checkbox) — assume the link is already in 16/16 LINK_IDLE state; skip the bringup_pair_converge.sh loop. Use when the link is already up.
  • Run (button) — start the sweep. If checkboxes are clear, will deploy + converge first. Acquires the bridge1 lease via fpgahub.
  • Abort (button) — stops the in-progress sweep at the next safe phase boundary. Lease is held until released.
  • Refresh lease (button) — re-acquires the bridge1 lease (4-hour TTL) without re-deploying. Use when your lease is about to expire mid-investigation.
  • State indicator — shows the workflow stage (idle / leasing / deploying / converging / sweeping / done / error).
  • Lease badge (top right) — shows the current bridge1 lease holder. lease: free means the boards are available. lease: <user> means someone holds it. queue: N is the FCFS queue depth waiting for the lease.

How to read the heatmap

  • X-axis: lanes L0-L7.
  • Y-axis: swi_phase_offset value (0 at top, 15 at bottom).
  • Green cell: at this phase, this lane was reported lane_locked = 1 (the matcher locked within tolerance).
  • Red cell: at this phase, the lane was NOT locked (matcher saw d ≥ 4).
  • Healthy pattern: one ROW all-green (the correct global phase locks all 8 lanes), all other rows all-red.
  • Per-lane heterogeneity pattern (different green rows for different lanes, no single all-green row): the calibrator did NOT pick a wide-margin eye centre, and lanes need different phases. Often visible as a symptom of the dwell_min_dist calibrator bug (see docs/CALIBRATOR_HW_FAILURE_AUDIT_2026_05_29.md).
