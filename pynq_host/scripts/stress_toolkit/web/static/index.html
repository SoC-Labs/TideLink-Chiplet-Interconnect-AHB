About this tool / what each test mode does

What this tool is for

A sibling to the live-lane-phase GUI (port 8088), focused on functional stress testing rather than channel characterisation. Picks a test mode, opens the bridge1 lease, optionally redeploys + converges, then runs the mode and streams live progress + pass/fail stats over SSE.

A passive PHY-health monitor runs in the background of the AHB / doorbell / PTP / auto modes — if it sees a canary fail, wiring alarm, or structured-noise alarm, it sets a kill-switch and the main test stops cleanly.

Test modes

  • AHB packet stress — write packets to the AHB_TX aperture, read them back on the peer's AHB_FIFO, verify bit-exact roundtrip + credit accounting. Tunable packet size (1..1024 words) and count (1..100k). Direction: M->S, S->M, or both alternating.
  • Doorbell volume — flood APB REG_DOORBELL (offset 0x14) and verify peer's DOORBELL_RESP_ACC grew by N x MAX_CREDITS (4096). APB writes are wedge-safe — this test is usable even on a partially broken link.
  • PTP HW sync — port of bringup_ptp_sync.sh. Programmes both PHCs with distinct initial times, enables PTP RX + the autonomous HW_SYNC initiator at 128 Hz, and tracks |slave-master| offset vs time on a Plotly line chart. Pass = locked AND |offset| < 500 ns for 10 consecutive samples.
  • PHY health — passive 1 Hz poll of the new tidelink_gpio_phy_apb_regs slave at 0x4403_2160. Per-lane noise (raw / voted), wiring status, canary pass/fail, structured-noise alarm. Useful as a baseline before any test or as a soak monitor.
  • FCSM monitor — 10 Hz poll of SWI_LANE_STATUS @ 0x4403_2108. Tracks locked count, fault count, cal_done, FCSM state, LL_RX state, ECC counters. Used as a sentinel — any drift away from LINK_IDLE trips the alarm.
  • AUTO — randomised mix of the above 5 for a user-picked duration. Maintains a running pass/fail table by test type.

Safety

  • AHB_TX writes are wedge-prone — the AHB stress test gates on link-up first (16/16 + cal_done + FCSM == LINK_IDLE). If the FCSM sentinel detects a state change away from LINK_IDLE mid-test, the test aborts immediately.
  • All other modes (doorbell, PTP, PHY health, FCSM) only write APB / PHC / PMOD — they never touch AHB_TX so they are wedge-safe even on a bad link.
  • The lease is held for the duration of the run; the heartbeat keeps it alive. Click Refresh lease to extend it without re-running.
