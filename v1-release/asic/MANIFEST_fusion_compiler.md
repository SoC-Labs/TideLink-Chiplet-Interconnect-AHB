## Integration notes

1. Drop into chip-top FC: read_lef + read_def + read_sdc; mark `u_tidelink_top`
   as a fixed hard block, or open the NDM block directly for NDM-based PnR.
2. Required clocks: `hclk`, `phc_clk`, `user_ref_clk`, `scan_clk`, `pad_clk_rx`.
3. Required resets (async): `hresetn`, `phc_resetn`, `poresetn`.
4. AHB direction-of-data signals follow protocol exactly — note in particular
   that `ahb_mng_hready` is an INPUT (slave→manager); this was a bug in earlier
   RTL and is now corrected. See BRINGUP_REPORT.md Appendix A for details.
5. Single power domain (`VDD` = 1.08 V core, `VSS` = 0 V) inside the partition.
6. LEC: `cd ../formality && make lec` for RTL→netlist equivalence check.
   Current residuals: 264 Wlink Chisel synth-transform DFFs (iteratively skipped);
   downstream cones all verify. Set `FC_PRESERVE_WLINK_FCSM=on` to eliminate them
   at the cost of some area on the Wlink modules.
